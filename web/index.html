Install GateMCU

Flash the latest GateMCU firmware to your NodeMCU directly from this browser.

GateMCU for NodeMCU ESP8266 Latest stable firmware
Use Chrome, Edge, or another browser with Web Serial support.

Existing device: installing firmware can erase saved Wi-Fi, password, WireGuard, and forwarding settings. Save anything you need before continuing.

Before you install

  1. Use Chrome or Microsoft Edge on a desktop computer.
  2. Connect the NodeMCU with a USB data cable and close other serial monitor tabs.
  3. Select Install GateMCU, choose the device’s serial port, then confirm.
USB flashing uses Web Serial. iPhone and iPad browsers are not supported. Release files
